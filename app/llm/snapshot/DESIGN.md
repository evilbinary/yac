# 快照并行（Snapshot LM）

`app/llm` 下的第三个实验：不写自回归「打印机」，写扩散式「快门」。

形态由本文定。**先在浮点里证明能填空、能快门**（`train_float.py`），再 port 到 `snapshot.yac`。Yac 侧的袋特征 / 只训 Wout / T=16 小词表已经证伪：mask-acc 贴着 maj，probe 可为 0，生成塌成标点。那些是运行时约束下的旧实现，不是目标架构。

架构按「长度增加时迭代次数不跟着涨」来设计：K 是超参，与 T 无关。

## 1. 要证明什么

自回归（trigram、现有 causal Transformer）是：已知左边，猜下一个字，长度 N 就要 N 次前向。

快照并行是：先铺一整张底片（长度固定的噪声序列），再对**所有位置同时**显影若干次。N=50 和 N=200 都是 K 次**全局曝光**（一次前向看完整张画布），不是从上到下、从左到右扫一遍。

成功标准是四件可观察的事。前三条证明快门是真的；第四条才是这张底片拿来干什么——**顺着冻结提示把后文写通**，后续为做多轮闲聊机器人打基础。

1. 一次前向写出整段 logits，而不是 `argmax` 出一个字再拼回去。
2. 增加 K，整段从「雪花」变成可读；K 太小则糊，K 够用后收益变平。
3. 提示词只约束底片的一部分（左侧若干字冻结），其余位置按置信度并行填实。
4. **流畅续写：** 冻结区右边应读作提示的后续（同一口气、同一路人物与句法），而不是词袋乱拼或整页高频字。K 足够时，人扫一眼能当成「接着往下写」，即使个别字仍错。

做不到 1–3，就还是换皮的自回归。只有 1–3、没有 4，快门立住了但底片不能用。

训练主指标仍是 **MASK 位填空 acc**（必须明显高于 maj），用来判断网络有没有在学上下文。续写好不好**另看 K 画布**（infer 中间帧 + 终帧），不计入 acc，也不用 80% cloze 当续写及格线。不要把 BERT 的 10% keep 算进 acc——那是抄输入，会把 8% 的真挖洞吹成 15%。

## 2. 快门对照

| 相机 | 本实验 |
| --- | --- |
| 取景框 | 输出长度 T（当前 Python：64） |
| 白纸底片 | 长度 T 的画布：提示区真字，生成区 `[MASK]` |
| 按下快门 | 一次双向 Transformer 前向，看整张画布 |
| 显影次数 | 去噪步数 K（4 / 8 / 16） |
| 淡影 → 清晰 | 先主干（高信息量）后细节；每步只提交一部分 MASK |
| 成片 | K 步之后没有 MASK |
| 连拍 | 第二阶段：语义帧（第一版不做） |

### 2.1 扫描方向：没有方向

- 一步之内，位置 0 和位置 T-1 **一起**出 logits。
- 揭哪些 MASK 按**信息量 × 置信度**（先主干后细节），不按阅读顺序、不按行号。先揭左边再揭右边 = 换皮自回归。
- 终端打成一行字，只是人读的序列化。
- 训练挖洞各位置独立随机，不按扫描线，**不要把「挖后缀」当一半训练任务**（那是因果监督，混进来快门就假了）。

### 2.2 一张快门的硬规则

\[
\mathrm{logits} = f(\text{整张画布})
\]

`forward` 只读 `ids`，写出 `logits[T][V]`。揭 MASK 发生在返回之后，**本步选中的格子一次提交**。禁止：算完位置 i 写回 `ids[i]`，再用新画布去填位置 j（步内卷帘）。重复惩罚、温度只允许作用在**已经算完的这一张 logits** 上，再同时写下本步的 m 格。

步与步之间才有时间：第 k 步的输入包含第 k−1 步已揭开的字。层数是透镜厚度，不是扫行。causal Transformer 不能当这张快门。

## 3. 第一阶段：单帧

离散 MASK 扩散 / MaskGIT：词表是整数下标。Python 用浮点 CE；Yac 仍用整数下标 + `BYTES` 存盘，不要 `str_cat` 拼权重。

### 3.1 画布

`ids[0..T)`。

- 特殊字：`[PAD]` `[UNK]` `[MASK]`。OOV 编成 UNK，不要丢掉导致提示空画布。
- 推理：提示按**原词序**写进画布真实下标（能放下的都冻，不搬格）。其余开场全 `[MASK]`。冻结格永不改写。
- T 固定。短则 PAD（训练窗）或截断；不做「先预测这篇有几个 token」。
- 显影不靠布局模板区分主干/细节，而靠 K 步调度：先主干后细节（§3.4）。

### 3.2 噪声

对一条长 T 的真窗口（书上滑动切片）：

1. **训练：cosine 动态掩码率** r = 0.10 + 0.80·cos(u·π/2)，u~U(0,1)，因此更多样本靠近第一帧高掩码。各位置独立抛硬币。不要固定 15%，也不要把挖后缀做成一半任务。
2. 约 **35%** 行是生成同族：在这条真窗口的**原下标**上留下 2–8 个可见字，其余全 MASK。一半随机抽若干真实下标；一半留下窗内本来就连续的 1–2 段短语。
3. 不要 span 夹心挖洞，也不要在训练里铺右侧 PAD 短洞（已证伪：会把填空头冲到 maj）。损失只在 MASK 上。
4. 评价仍打 r=15%、r=50%、r=90%（独立挖洞，用来对照 cloze，不是生成模板）。

### 3.3 网络结构

必须改掉 causal 的两点：位置 t 能看见整张画布；**每个位置各自一份 logits**。实现以 `train_float.py` 的 `SnapshotLM` 为准；Yac port 对齐这一张图，不要对齐旧袋模型。

语料：全书 `app/llm/xyj.txt`（约 80 万字），不要 80KB 切片当主实验。词表：频次 cap 4096 + `[PAD]` `[UNK]` `[MASK]`，稀有字 UNK。

#### 3.3.1 总图

输入 `ids: (B, T)` 整数下标。全程无因果遮罩。

```
ids ──► tok[V,d] ──► + ──► Dropout ──► Block × L ──► LN ──► h (B,T,d)
pos[T,d] ───────────┘                      │
                                           ▼
                              logits = h @ tok.weightᵀ     (B,T,V)
                              训练洞：h[pick] @ tok.weightᵀ
```

`Block` 是 Pre-LN 残差块（GPT-2 风格，不是 Post-LN BERT）：

```
x ──► LN ──► QKV ──► RoPE(q,k) ──► SDPA(可选 PAD 屏蔽) ──► Wo ──► + ──► x
                                                                  │
x ────────────────────────────────────────────────────────────────┘
                                                                  │
     ┌────────────────────────────────────────────────────────────┘
     ▼
x ──► LN ──► Linear(d,ff) ──► GELU ──► Drop ──► Linear(ff,d) ──► Drop ──► + ──► x
```

层是透镜厚度：4 层仍是同一张底片进、整图 `h` 出，不是扫 4 行。

#### 3.3.2 嵌入

| 模块 | 形状 | 说明 |
| --- | --- | --- |
| `tok` | `(V, d)` | 字符 embedding；`padding_idx = PAD`，该行保持 0 |
| `pos` | `(T, d)` | **学到的**位置向量，不是正弦表 |
| 相加 | `(B, T, d)` | `x = drop(tok[ids] + pos[0:T])` |

PAD 出现时，注意力对 PAD **键**加 `-inf`（不看垫字）。训练窗几乎总是满 T，这条很少触发。

初值：`tok` / `pos` / 所有 `Linear` 的 weight ~ N(0, 0.02²)，bias 0。不要用 PyTorch Linear 默认的大方差，早期 CE 会到几十。

#### 3.3.3 注意力块

默认：`L=4`，`H=6`，`d=192`，`d_h = d/H = 32`，`ff=768`，dropout 0.05。

一次块内：

1. `h = LN(x)`
2. `QKV = Linear(d → 3d)(h)`，拆成 `q,k,v`，形状 `(B, H, T, d_h)`
3. 对 `q,k` 做 **RoPE**（不转 `v`），再 `SDPA(q,k,v)`：缩放 `1/√d_h`，训练时 attention dropout 0.05
4. 拼回头：`(B, T, d)`，再 `Wo: Linear(d → d)`
5. `x ← x + attn_out`（注意力输出不再额外 Dropout，SDPA 里已经有）
6. `x ← x + MLP(LN(x))`，MLP 宽 `ff=4d`，GELU

**RoPE**（代替对称 ALiBi，不要两套相对位置叠在一起）：把位置 `t` 的旋转作用在每个头的 Q/K 上，`θ_i = 10000^{-2i/d_h}`。全程仍双向、无因果遮罩。所有 `[MASK]` 共享同一个 `tok[MASK]`，旋转后不同洞看不同邻居，避免 `h` 塌成同一方向。绝对 `pos[T,d]` 仍加在 embedding 上。

禁止：causal mask、只看左边的下三角、按阅读顺序限制可见集。

#### 3.3.4 读出（绑定 embedding）

最后再 `LN`，然后：

\[
\mathrm{logits}_{b,t,v} = h_{b,t}\cdot E_v
\]

`E` 就是 `tok.weight`，没有单独的 `Wout`。训练只对洞做这一步（`logits_pick`），推理对 T 个位置都做。不要再训一个解绑的分类头——V=4096 时那是多余的大矩阵，也拆掉「字的向量既当输入又当输出类」。

整网都训（AdamW lr=3e-4，wd=0.01）。不要冻 QKV 只训读出。

#### 3.3.5 形状、参数、复杂度

| 符号 | 值 | 张量 |
| --- | --- | --- |
| B | 256（GPU）/ 96（CPU） | 训练 batch |
| T | 64 | 底片长度 |
| d | 192 | 隐宽 |
| H | 6 | 头 |
| L | 4 | 块 |
| V | ≤4096 | 词表 |
| 参数 | ≈2.58M | 其中 embedding `V·d` 约占 0.79M |

一次前向 O(T²·d + T·d·V)（注意力 + 读出）。K 步推理乘 K。文档和日志写「前向次数 = K」，不要和每步墙钟混谈。

#### 3.3.6 禁止的替代结构

这些已经在本仓库证伪，port 时不要「为了 Yac 好写」退回去：

- 左右可见袋 + 邻字 one-hot（784 维）当唯一特征
- 在该 one-hot 上叠一层假 QKV
- 只训 Wout / 冻注意力为近单位阵
- T=16、V≈256、语料 80KB 当主规格

那些配置 mask-acc≈maj，MASK 隐向量互相 cosine≈1，生成标点循环。

### 3.4 显影（推理）

快照显影是**从句子主干到细节**：K 步仍整页并行，但每步写什么随时间片变。不是「快门一按全息显影」，也不是左/中/铺三种几何布局。

1. 画布 = 提示留在原下标 + 其余 `[MASK]`。
2. 词表有一份**信息量**（词表按语料频次降序，靠后的字 IDF 高）。融合分：
   \[
   \mathrm{score} = p(\mathrm{char}\mid\mathrm{canvas})\cdot \mathrm{info}^{\beta}
   \]
3. 前 **1/3** 步（主干）：\(\beta=\) `GEN_BETA1`。少填、过阈才落。主干步结束后这些格**锁定**，后面不得改写。
4. 后 **2/3** 步（细节）：只填仍为 MASK 的格，**优先左邻已是真字**的续写洞。句号/问号后的格不填。已有「道/叫」则不再开第二轮说话动词。夹心且不稳的格重涂。禁止整页覆盖主干。
5. 最后一步**不强制填满**；置信度不够或句号后的洞保持 MASK。提示冻结格全程不改。硬过滤：不写 PAD/UNK/MASK、`[]` 与 ASCII 数字；换行降权。

默认 K=`GEN_K`（24）。K=8 主干窗口太短，锁不住「牛魔王」一类短语。

`infer` 必须 dump **每一步**画布：step 0（提示 + ░）到 step K（final）。只打首尾看不见主干怎么长成细节。

```text
python -u app/llm/snapshot/train_float.py infer app/llm/snapshot/snapshot_bert.pt 悟空
python -u app/llm/snapshot/train_float.py infer app/llm/snapshot/snapshot_bert.pt 孙悟空打妖怪 24
```

### 3.5 训练与指标

滑动窗口切 T 字（stride=64，每轮步数少、GPU 约 25s/32 epoch；stride=32 会把窗数翻倍）。不要因果 `train_step`。只在洞上 CE，一次前向。checkpoint 含 Adam 状态，无 `new` 则接着训。

每个 epoch：

```
epoch 3  mask-acc ~20%  maj ~7%  nll 4.93  hit 48842 / 235618
         test mask-acc ~24%  nll 4.71  hit 2919 / 12126
K=1 ...
K=8 ...
```

| 字段 | 含义 |
| --- | --- |
| `mask-acc` | 猜对的洞 / 挖的洞。主指标。乱猜 ≈ 100/V |
| `maj` | 每个洞都填本批金标众数。**acc 必须明显高于 maj** |
| `nll` | 洞上平均 CE（nat） |
| `hit / n` | acc 的分子分母 |
| `test` | 后 10% 窗口，不更新 |
| `probe` | 打乱可见字后，MASK 位预测改变的比例。0 = 忽略上下文 |

不要报含可见字的 full-acc，也不要把 keep 位算进去。生成好不好看 K 画布，不计入 acc。

Python 权重：`snapshot_bert.pt`（含 vocab）。Yac：`snapshot.w`，文件头标明 bidir，禁止和 causal `transformer.w` 混用。改结构必须 `new`，不能接着袋模型的权重训。

### 3.6 和另外两个例子

| | `trigram/` | `transformer/` | `snapshot/` |
| --- | --- | --- | --- |
| 生成顺序 | 左→右 | 左→右 | 全图同时，K 步 |
| 前向次数 | O(N) | O(N) | O(K) |
| 注意力 | 无 | causal | bidirectional + RoPE |
| 读出 | 下一字 | 最后位置 | 每个位置 |
| 噪声 | 无 | 无 | 随机 MASK（多档 r） |
| 先跑通 | — | Yac 整数 | **Python 浮点**，再 port Yac |

## 5. 第二阶段：连续帧（先写在纸上）

单帧 T 讲不了长回复。宏观取景决定下一帧，微观快门跑第一阶段。接口预留 `denoise_frame(m, prefix, t, k)`。第一版整段 = 一帧，不要先训两个网。

## 6. 超参（当前 Python 默认）

| 名 | 默认 | 含义 |
| --- | --- | --- |
| T | 64 | 底片字数 |
| d | 192 | 宽 |
| layers / heads / FF | 4 / 6 / 768 | 双向块 |
| V | ≤4096 | 字符 cap |
| K | 24 | 推理显影次数（可用 argv 覆盖） |
| r | cosine 动态 ∈[0.10,0.90] | 独立随机洞；eval 另报 15/50/90% |
| stride | 64 | 滑动窗步长 |
| drop | 0.05 | 残差 MLP / embed |
| freeze | 8 | 训练生成同族留下可见字的个数上界 |
| lr / wd | 6e-4 cosine / 0.01 | AdamW，存 optimizer |

合理现象（在 mask-acc ≫ maj、probe ≠ 0 之后才谈）：

- 提示「猴 / 唐」时生成区更常出现「王 / 僧」一类搭配，而不是均匀乱码或纯「，」。
- K=1 比 K=8 更容易整页同一个高频字；K=8 应能读出一两句像续写的话，而不是只有壳（「行者道」）没有后文。
- 冻结提示在 K 步里始终不动；续写从冻结区右缘接上，不改提示、不另起炉灶成无关段落。
- 反例（未达标）：`猴王，，来来来一一`，或人物对了但字序像洗牌。

若 mask-acc 贴 maj、MASK 隐向量互相 cosine≈1：先查注意力是否袋化，再查是不是把 keep 算进了 acc。不要靠调 lr 假装在学。

## 7. 明确不做

- 连续空间扩散再 round 到词表。
- 与长度成正比的自回归循环，包括挖后缀当主任务、按左→右揭 MASK、步内写回再算下一格。本阶段不另训规划器；主干→细节只在同一张 MaskGIT 显影里做。
- 从 causal `transformer.w` 或旧袋模型权重热启动。
- 子词 BPE、多机数据并行（「并行」指序列维同时更新）。
- 把 trigram 计数表伪装成一步填空。
- 用邻字 one-hot 假注意力当「已经是 Transformer」。

## 8. 实现顺序

1. Python：双向块 + 每位置 logits；全 MASK 输入能跑完。
2. MLM：只计真洞的 `mask-acc` / `maj` / nll；acc 随 epoch 升且高于 maj；probe > 0。
3. MaskGIT：一步同时揭格；infer 打印中间帧；对照 K=1/8/16。
4. 训练 r 覆盖高掩码，使 generate 与训练同族。
5. 续写：固定几个提示（如「悟空」「猴」「唐僧」）对照 K=1/8/16，人读终帧是否接得上；未通顺不要急着 port。
6. 快门 + 续写都过后再 port Yac（整网或等价结构，不要退回只训 Wout）。
7. （可选）帧接口。

第 2 步没过不要谈生成。第 3 步没有中间帧，快门实验不算立住。第 5 步不过，只说明芯片在感光，底片还不能当续写用。


## 9. 说明

扩散式「快门」**不是网络长得像相机**，而是 **生成程序**：一张固定底片、噪声、K 次全局曝光、按置信度显影。网络只是那块感光芯片（双向 Transformer）。

具体落在这几处。

**1. 底片，不是纸带**

推理开场不是从左往右长句子，而是长度锁定为 T 的整页：

- 提示按原词序冻结（取景框）
- 其余全是 `[MASK]`（未曝光的白片）

对应 `blank_canvas`：先铺满 MASK，再按提示自身的下标写入，不搬格。

显影从主干到细节：前 1/3 步抬信息量、过阈才落笔；后 2/3 步常规概率接虚词和标点。

**2. 噪声是挖洞，不是高斯**

训练把真窗口里一部分字变成 MASK（cosine 动态 r∈[10%, 90%]）。这是离散扩散 / MaskGIT 的加噪，不是逐步加高斯再 round。洞越多，越接近推理时的「第一帧雪花」。

**3. 一次前向 = 按一次快门**

`logits = f(整张 ids)`，位置 0 和 T−1 同一张输入上一起出分。没有「先揭左边再拿新画布揭右边」。这是全局快门；causal Transformer 是卷帘（右边被挡板挡住）。

DESIGN §2.2 和代码里的 `model(canvas)` / `encode(ids)` 就是这一张。

**4. K 步显影，K 与 T 无关**

`denoise_ids` 循环 K 次：

1. 对**当前整页**做一次前向  
2. 非冻结格全部写出候选（硬过滤 + 邻字惩罚在这张 logits 上）  
3. 按 cosine 把置信度最低的格**重涂回 MASK**  
4. 下一张快门看见剩下的高置信度字；主题冻结格不改

T=64 用 K=8，和 T=200 用 K=8 是同一套曝光次数。自回归长度 N 就要 N 次前向，这里不是。

**5. 中间帧才是快门可观察**

`infer` 打 `step 0` … `step K` 每一步。K=1 应更糊、更容易整页同一个高频字；K 增大应先出主干再出细节。这是实验要证明的第二条，不是聊天质量。

**没有体现在哪里（容易误会）**

- 4 层 × 6 头、RoPE、AdamW：这是感光元件怎么做，**任何双向填空都能用**。没有它们快门也定义得清，只是底片会糊成逗号。
- 训练时的 15% mask-acc：这是「底片上随机挖几个洞会不会补对」，是主指标，但还不是快门本身。快门是 **高掩码 + K 次并行揭格**。
- 步内按置信度选哪些格：这是显影液先固轮廓，**不是**从左到右扫；若改成按下标揭开，快门就假了。

一句话：**扩散在「MASK 噪声 + 逐步去噪」；快门在「整页一次曝光、K 与长度无关、一步多格同时亮」。** 网络结构是为了让这次曝光能看全图，它自己不是快门。
