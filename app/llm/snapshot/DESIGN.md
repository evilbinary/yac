# 快照并行（Snapshot LM）

`app/llm` 下的第三个实验：不写自回归「打印机」，写扩散式「快门」。

本文定形态，代码在同目录 `snapshot.yac` / `train.yac` / `infer.yac`。演示规模仍是玩具（字符级、短序列），架构按「长度增加时迭代次数不跟着涨」来设计。

## 1. 要证明什么

自回归（trigram、现有 1 层 causal Transformer）是：已知左边，猜下一个字，长度 N 就要 N 次前向。

快照并行是：先铺一整张底片（长度固定的噪声序列），再对**所有位置同时**显影若干次。迭代次数 K 是超参，与 N 无关。N=50 和 N=200 都是 K 次**全局曝光**（一次前向看完整张画布），不是从上到下、从左到右扫一遍。

在这个仓库里，成功标准不是流畅闲聊，而是三件可观察的事：

1. 一次前向写出整段，而不是 `argmax` 出一个字再拼回去。
2. 增加 K，整段从「雪花」变成可读；K 太小则糊，K 够用后收益变平。
3. 提示词（取景）只约束底片的一部分（例如左侧若干字冻结），其余位置并行填实。

做不到这三条，就还是换皮的自回归。

## 2. 快门对照

| 相机 | 本实验 |
| --- | --- |
| 取景框 | 输出长度 T（第一版固定，例如 16/32 字） |
| 白纸底片 | 长度 T 的画布：提示区保留真字，生成区全 `[MASK]` 或随机字 |
| 按下快门 | 第一次双向 Transformer 前向，看整张画布 |
| 显影液 / 曝光次数 | 去噪步数 K（建议 4 / 8 / 16，可命令行改） |
| 淡影 → 清晰 | 每步只把一部分仍模糊的位置写成词表里的字 |
| 成片 | K 步之后画布上不再有 MASK |
| 连拍 / 录像 | 第二阶段：按句或按段出「语义帧」，帧间用上一帧作条件 |

传统自回归没有「整张底片」，只有一条不断往右长的纸带。

### 2.1 扫描方向：没有方向

人眼看「整页上面是什么样」，在一次注视里不是 CRT 那样从上到下逐行扫，也不是读书那样从左到右过每一个字。感光是**并行**的：这一瞬间视野里的点同时进网膜。中央凹更清楚、周边更糊，那是分辨率不均匀，不是扫描顺序。

相机对应关系：

| 机制 | 像什么 | 本实验 |
| --- | --- | --- |
| 卷帘快门 / 打印机 / 自回归 | 有扫行：上→下或左→右 | **不做** |
| 全局快门 / 一次注视 | 全画面同一时刻曝光 | 每一步 Transformer 前向 |
| 眼跳（下一眼看别处） | 时间上的下一帧 | 第二阶段「连续帧」，不是帧内扫行 |

因此：

- 一步之内，位置 0 和位置 T-1 **一起**出 logits，没有「先算上面再算下面」。
- 揭开哪些 MASK 只按**置信度**（轮廓先实、虚词后填），不按阅读顺序、不按行号。若先揭左边再揭右边，就是换皮自回归，快门假的。
- 终端把画布打成一行字，那只是人读的序列化，不是模型的扫描方向。以后若折成多行「照片」显示，仍然是整帧一起更新。

训练挖洞也是各位置独立随机，不按从上到下的扫描线加噪。

### 2.2 一次前向算不算「同一时刻曝光」

算，指的是**数学上的一张快门**，不是芯片上所有晶体管同时跳变。

双向 Transformer 一步做的事：

\[
\mathrm{logits} = f(\text{整张画布})
\]

每个位置的分数都是**同一张**输入底片的函数。自注意力里 QK 对是全对全：格子 i 看见的是这一步开始时大家都在的状态，不是「i 已经揭开之后」的新画面。这和全局快门一样——光子同时落到所有像素上，再用这一帧去做显影。

和真相机的差别，必须说清楚：

1. **机器上仍是循环。** Yac 里会 `for i`、`for j` 算注意力。只要循环只读旧画布、把新 logits 写到另一块缓冲，结果与循环次序无关（定点溢出除外）。这叫语义并行。若算完位置 0 立刻写回 `ids[0]`，再拿新 `ids` 去算位置 1，那就变成卷帘快门，一步之内已经有时间先后。
2. **层与层是厚度，不是扫行。** 2 层 = 光穿过两片透镜，仍然是同一张底片进、整图 logits 出。不要把层数理解成从上往下扫。
3. **K 步是多次曝光 / 显影，不是一张快门里的扫描。** 第 k 步的输入才包含第 k-1 步已经揭开的字。步与步之间有时间；一步之内没有扫描方向。
4. **现有 causal Transformer 不能当这张快门。** 它规定位置 t 看不见 t 右边，等于传感器右半边被挡板遮住，不是全画面曝光。

实现时一条硬规则：`forward` 只读 `ids`，写出 `logits[T][V]`；揭 MASK 发生在 `forward` 返回之后，一次提交。

## 3. 第一阶段：单帧快照（先做这个）

离散扩散 / MaskGIT 一类，比连续向量扩散更适合当前 Yac 运行时：词表是整数下标，不必在每个位置上维护浮点 x。

IEEE f64 已经能用，第一版仍然以**整数下标 + 可选定点 logits** 为主，和现有 `transformer/` 同一套存盘教训（`BYTES` 写权重，不要 `str_cat` 拼大字符串）。

### 3.1 画布

令 `ids[0..T)` 为当前底片。

- 词表比语料多一个特殊字 `[MASK]`（建议放在词表末尾，避免再踩「下标 0 = 你」的解码陷阱）。
- 提示：把用户字符串编进画布左侧（或任意冻结区），这些下标在显影时**永不改写**。
- 其余位置：推理开始时全是 `[MASK]`。

长度：第一版 T 固定（16 或 32）。语料行短就右填 MASK；超长就截断。不做「先预测这篇有 50 个 token」——那是第二阶段的取景器。

### 3.2 噪声（训练时的快门前）

对一条长度为 T 的真句（可含提示左段）：

1. 抽一个掩码率 r ∈ (0,1]，或从离散集合 `{25%, 50%, 75%, 100%}` 里抽。
2. 生成区每个位置独立以概率 r 变成 `[MASK]`（或换成随机字，比例很小，例如 10% 随机 / 90% MASK，模仿 BERT 噪声）。
3. 提示区不掩。

这不是逐步加高斯噪声，是**随机挖洞**。洞越多，越接近「只看到雪花」的第一帧。

### 3.3 对焦：双向 Transformer

现有 `transformer/` 是 **causal**：位置 t 只看 0..t，最后只读出 t=T-1 的 logits。快照必须改掉这两点。

- 注意力：**全双向**。位置 i 可以看整张画布（提示 + MASK + 已显影的字）。没有因果遮罩。
- 读出：**每个位置各自一份 logits**，`logits[i][v]` = 位置 i 填词 v 的分数。一次前向是 T 个分类头，不是 1 个。
- 结构仍保持玩具级，便于在原生 yc 里跑通：

  - 1 层、1 头（第二版可加到 2 层）
  - d=8 或 16，T=16 或 32
  - 字符级 UTF-8 词表，共用 `app/llm/corpus.txt`

位置编码继续用简易的「第 0 维加 i·c」，不必上正弦表。

前向一次的复杂度是 O(T²·d + T·d·V)，K 次就是乘 K。相对自回归的 N 次「只算最后一个位置」，这里每次更贵，但 N 大时 K≪N 才是故事。演示里 T 很小，速度优势看不出来，文档和计数器要写清楚「前向次数 = K」，不要和「每步耗时」混为一谈。

### 3.4 显影规则（推理）

经典 MaskGIT 调度，和「每次把淡影涂清楚一点」对齐：

1. 画布 = 提示 + 全 MASK。
2. 重复 K 次：
   - 对当前画布做一次双向前向。
   - 只在**仍为 MASK** 的位置上看 `argmax` 或采样，得到候选字和置信度（logit 最大项，或 `exp(logit-max)` 的质量）。
   - 本步只**揭开** m 个位置：在仍为 MASK 的格子里取置信度最高的 m 个（空间上可以是画布中间、两端、任意处同时亮起来）。m 随步数增加，或 `ceil(剩余MASK / 剩余步数)`。禁止「按下标 i=0,1,2… 依次揭开」。
   - 已揭开的字下一轮当作上下文，不再改（贪婪版）。可选：低置信度允许以后重涂（真正的扩散；第一版不做，以免调试时画面来回闪）。
3. K 步后若还有 MASK，最后一步全部揭开。

「曝光不足」：K=1 时等于一次填完整张图，位置之间没机会互相照看刚写下的字，容易重复、不通。「曝光适中」：K=8 左右，先钉住几个高置信轮廓（如「今天」「天气」），再填虚词和标点。

采样温度只作用于「本步被揭开的那些位置」，不要对已冻结的提示做采样。

### 3.5 训练

每个窗口一条损失：只在被挖掉的位置上算交叉熵（和 BERT MLM 相同）。提示区和未掩位置不计入。

反向第一版只训 **Wout + 被掩位置的 embedding**，注意力权重可先冻成近单位阵加噪声——与现有 transformer 的「先把读出训活」同一策略。整数定点则学习率仍用「除以 Σw 再除一个常数 + clip」。

一个 epoch 扫语料时，用滑动窗口切 T 字（不够就 MASK 垫到 T）。不要用因果「用前 T 字预测第 T+1 字」那套 `train_step`。

准确率打印建议两行：

- `mask-acc`：被掩位置上 argmax 是否等于真字（训练是否在学填空）
- `full-acc`：整张画布（含可见字）是否完全一致（会虚高，只作参考）

### 3.6 和现有两个例子怎么并列

| | `trigram/` | `transformer/` | `snapshot/` |
| --- | --- | --- | --- |
| 生成顺序 | 左→右 | 左→右 | 全图同时，K 步 |
| 前向次数 | O(N) | O(N) | O(K) |
| 注意力 | 无（计数） | causal | bidirectional |
| 读出 | 下一字 | 最后位置 | 每个位置 |
| 噪声 | 无 | 无 | MASK / 随机字 |
| 默认产物 | 当场数完就生成 | `transformer.w` | `snapshot.w` |

语料继续共用 `app/llm/corpus.txt`。不要和 causal 权重混用：遮罩不同，文件头要写 `V d T S Kmax bidir=1`。

## 4. 目录（实现时）

```
app/llm/
  corpus.txt
  README.md
  trigram/main.yac
  transformer/          # 打印机
  snapshot/             # 快门
    DESIGN.md           # 本文
    snapshot.yac        # package snapshot：词表、双向前向、掩码、去噪一步
    train.yac
    infer.yac
```

`import snapshot` 的包根是 `app/llm/snapshot`（`--pkg src-self,pkg,app/llm/snapshot`）。

建议 Makefile：

```text
make -C app llm-snapshot
# 即 llm-snapshot-train + llm-snapshot-infer

./app/llm/snapshot/train.exe app/llm/corpus.txt app/llm/snapshot/snapshot.w 5
./app/llm/snapshot/infer.exe app/llm/snapshot/snapshot.w 你好 8
# 提示「你好」，K=8 次显影，打印每步画布（MASK 显示为 ░）
```

`infer` 必须能 dump 中间帧，否则看不出「快门」：至少打印 step 0（全 MASK）、中间一步、最后一步。这是这个实验的主界面，不是可选项。

Windows 上函数参数仍建议 ≤5；双向注意力的循环拆成小函数，不要把 T、头、层、lr 塞进同一个调用。

存盘：整数列表走 `bytes_append`，词表用「长度 + 各字节」，与 transformer 修好的格式相同。

## 5. 第二阶段：连续帧（先写在纸上，第一版不做）

单帧 T 太短讲不了长回复。录像式生成：

1. **宏观取景**：一个很浅的模型（甚至规则）决定下一帧的长度和「镜头」——继续同一话题 / 换问句 / 结束。输入是上一帧的成片（或它的句向量：各位置 embedding 平均）。
2. **微观快门**：对这一帧跑第一阶段的 K 步并行显影。画布左侧可拼上一帧末尾若干字当重叠，相当于光流约束，减轻帧间跳戏。
3. 帧率：演示里一帧 = 一行对话或固定 16 字，不是墙钟 0.5 秒。

层次解码的接口预留为 `denoise_frame(m, prefix, t, k)`，train 第一版只调用它一次（整段 = 一帧）。不要第一周就训两个网络。

## 6. 超参（演示默认）

| 名 | 默认 | 含义 |
| --- | --- | --- |
| T | 16 | 一张底片的字数 |
| d | 8 | 宽 |
| layers | 1 | 双向层数 |
| heads | 1 | 头数 |
| K | 8 | 推理显影次数 |
| r | {0.25,0.5,0.75,1} | 训练掩码率 |
| S | 64 | 定点尺度（若仍用整数 softmax） |

语料约 600 字、V≈100 时，不要期待「上海秋天梧桐」那种开放生成。能看到的合理现象：

- 提示「你好」时，MASK 区更常出现「。 / 今天 / 啊」而不是均匀乱码。
- K=1 比 K=8 更容易整句重复同一个高频字。
- 冻结提示区，K 步过程中那两个字始终不动。

## 7. 明确不做（第一版）

- 连续空间扩散（每个位置一个 d 维向量再 round 到词表）：调试和定点都更痛。
- 与长度成正比的自回归循环，哪怕包一层「并行」外壳。
- 按阅读顺序 / 从上到下 / 从左到右揭 MASK（卷帘快门）。揭开顺序只允许置信度或随机。
- 从 causal `transformer.w` 热启动（遮罩不兼容）。
- 真实大参数、子词 BPE、多机并行。并行指**序列维上同时更新**，不是多核训练。
- 把 trigram 的计数表伪装成一步填空。

## 8. 实现顺序

1. 双向前向 + 每位置 logits；单元行为：全 MASK 输入也能跑完，不崩栈。
2. 训练 MLM，打印 `mask-acc`；acc 要随 epoch 升，不能只升 unigram。
3. MaskGIT 推理 + 逐步打印画布。
4. 命令行可调 K，方便对照「曝光」。
5. （可选）帧接口和重叠前缀。

第 3 步能出中间帧，这个实验才算立住。
